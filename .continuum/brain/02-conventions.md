# Conventions

## Rafiul's standing instructions

- **Short answers.** Two sentences beats a report; he stops reading long ones.
- **No em-dashes** in anything he will read.
- **Nothing is "done" without evidence.** HTTP 200 is not proof. Quote the
  output or the assertion that produced the figure.
- **No deploy, no push, no `active`, no SMS, no paid API call without his
  typed approval.** n8n API and MCP use on srv1836598 was approved for this
  project on 2026-11-11.
- **Backend is n8n.** Convex for the database and for anything n8n genuinely
  cannot do, and code only if n8n cannot.
- **Only what the client asks.** Report other problems; do not fix them
  uninvited.

## Code

- Comments explain **why**, especially why something is not the obvious
  choice. A comment that describes behaviour the code does not have is worse
  than no comment: a review on 2026-11-11 found three of them here, one
  asserting the public routes could not read another session while they
  could.
- Tests are plain scripts printing `ok` / `FAIL` lines and a count. No test
  framework. Run with `zsh widget/tests/run.sh`.
- Test first, and watch it fail first. A test that has never failed is not
  evidence.
- British English in anything a visitor or OMH reads.

## Dashboard

- Tokens live in the inline `<style>` in `app/lead-dashboard/layout.tsx`
  scoped to `#omh-dashboard`. Use `text-[var(--dash-accent-text)]`, never
  `text-amber-deep`. Do not give `#omh-dashboard` children `position:
  relative`.
- **Never show a zero that could be read as a measurement.** "Not set" and
  "0" are different facts. A channel with no spend prints "add spend", never
  £0, because £0 is a claim that it was free.
- **Every screen states what it left out.** Test traffic is excluded by one
  shared rule, `lib/dashboard/test-rows.ts`, and the count is printed.
- `?demo=1` swaps the whole source for `lib/dashboard/demo.ts` and puts a
  banner on every screen. Nothing is written in that mode.

## n8n

- Workflows are generated by `widget/n8n/build-workflows.py` and pushed by
  `push.py`, which matches **by name**: renaming a workflow creates a
  duplicate rather than updating it.
- `push.py --only <text>` pushes one. The payload carries no `active` field,
  so a live workflow stays live.
- Use `gate_inline()`, never `gate_source()`, for anything a Code node runs.
